# URO PRINT LAB v1.0.1

Windows 10／11 x64向けポータブル版です。

## ダウンロード

- `URO-Print-Lab-1.0.1-Windows-x64.zip`
- `URO-Print-Lab-1.0.1-OSS-Sources.zip`

## 起動

1. Windows版ZIPを「すべて展開」します。
2. `URO Print Lab.exe`を起動します。
3. AI補完が動かない場合は、Visual C++ v14 x64ランタイムとGPUドライバーを確認します。

## SHA-256

公開時に実ファイルの値を記載してください。

```text
[Windows版ZIPのSHA-256]
[OSSソースZIPのSHA-256]
```

## 注意

AIは文字や細部を変える場合があります。出力を元画像と比較してください。
動作条件と第三者ライセンスはZIP内の文書をご確認ください。
