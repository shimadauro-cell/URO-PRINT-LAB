# 公開チェックリスト

## Publicへ変更する前に必須

- [x] `LICENSE.md`の著作権者を、販売主体「島騨うろ」に設定する
- [x] `SUPPORT.md`の販売者名と問い合わせ先「X @shimadauro」を入力する
- [x] 公開先を`shimadauro-cell/URO-PRINT-LAB`に設定する
- [ ] X @shimadauroで、購入者や脆弱性報告者からDMを受信できる設定か確認する
- [ ] 販売ページに価格、提供方法、必要環境、問い合わせ先、返品・返金条件を表示する
- [ ] 最新Windows版を複数PCで確認する
- [ ] Windows版ZIPにOSSライセンスと対応ソースが含まれることを確認する
- [ ] ZIPとソース提供物のSHA-256をRelease本文へ掲載する
- [x] Git履歴にAPIキー、個人情報、購入者情報、未公開素材がないことを確認する
- [x] 独自素材について、商用同梱・公開表示・再配布権限を確認する
- [ ] 公開リポジトリのIssuesとSecurity案内を確認する

## GitHubでの配置

- Git履歴：このフォルダー内のソース、文書、小さな画像素材のみ
- GitHub Releases：Windows配布ZIP、OSS対応ソース、SHA-256
- Gitへ登録しないもの：AIモデル、実行ファイル、DLL、依存パッケージ、監査作業用展開物

公開リポジトリではGitHubの仕様上、閲覧者がForkやCloneを実行できます。
独自ライセンスは利用権を制限しますが、技術的なコピー自体を防止するものではありません。
